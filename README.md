# Open Ports Scanner

A simple async port scanner that scans ports 20-100 and identifies common services.

## Installation

```bash
git clone https://github.com/m00ncakes-dot/Open-ports-scanner.git
cd Open-ports-scanner
pip install rich pyfiglet
```

## Usage

```bash
python main.py
```

## Features
- Scan IPs from a text file
- Scan a single IP manually
- Async scanning for fast results
- Displays open ports with service names
